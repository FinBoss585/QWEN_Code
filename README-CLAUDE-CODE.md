## 🚀 Быстрая установка

### Linux / macOS

```bash
# 1. Включите VPN на Швецию
# 2. Запустите:
bash install-claude-code.sh
```

### Windows (PowerShell от имени администратора)

```powershell
# 1. Включите VPN на Швецию
# 2. Запустите:
Set-ExecutionPolicy Bypass -Scope Process -Force
.\install-claude-code.ps1
```

## 🌐 Настройка VPN для стабильной работы

### Рекомендуемые VPN-серверы (в порядке приоритета):

1. 🇸🇪 **Швеция** — стабильно, низкий пинг из России
2. 🇫🇮 **Финляндия** — ближайший, быстрый
3. 🇩🇪 **Германия** — стабильно
4. 🇳🇱 **Нидерланды** — стабильно

### Если VPN падает во время работы:

Claude Code кэширует сессии, но для новых запросов нужен VPN.  
Настройте **always-on VPN** или **kill switch**:

```bash
# Linux — проверка что VPN работает перед каждым запуском
# Добавьте в .bashrc:
alias claude='curl -s https://ipinfo.io/country | grep -q "^RU$" && echo "⚠️ Включите VPN!" || command claude'
```

## 🔧 Решение проблем

### Ошибка: "API connection failed" / "blocked"

**Причина:** VPN отключился или IP определяется как российский.

```bash
# Проверьте:
curl https://ipinfo.io/country
# Должно быть: SE (или другая не-RU страна)

# Если RU — переподключите VPN
```

### Ошибка: "Authentication failed"

**Причина:** Токен устарел или подписка неактивна.

```bash
# Перелогиньтесь:
claude login --force
```

### Ошибка: "Rate limit exceeded"

**Причина:** Превышен лимит подписки.

```bash
# Проверьте лимиты:
claude config list

# Решение: обновите подписку до Max
```

### Ошибка: "command not found: claude"

```bash
# Linux/macOS:
export PATH="$PATH:$(npm prefix -g)/bin"

# Windows:
# Перезапустите PowerShell от администратора
```

### Ошибка при оплате картой Узбекистана

1. Убедитесь что VPN → Швеция (не Россия!)
2. Попробуйте другой браузер (Chrome incognito)
3. Проверьте что карта поддерживает 3D Secure
4. Попробуйте другой VPN-сервер (Финляндия, Германия)
5. Обратитесь в банк — возможно блокируют международные транзакции

## 🔒 Безопасность

- Claude Code работает **локально** на вашем компьютере
- Код отправляется в Anthropic API только для анализа
- VPN шифрует трафик между вами и Anthropic
- API-ключи хранятся в `~/.claude/` — не публикуйте эту папку
- Anthropic не передаёт данные третьим лицам (для платных подписок)
